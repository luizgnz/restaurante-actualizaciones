# Actualizaciones de Restaurante

Este repositorio público distribuye los instaladores verificados de Restaurante. El código fuente permanece privado.

Descarga los paquetes desde Releases. Cada entrega incluye el EXE, MANIFIESTO.json, SHA256.txt e instrucciones. El actualizador de Restaurante consulta este repositorio sin cuenta de GitHub y verifica el paquete antes de instalarlo.

La aplicación conserva sus datos y utiliza respaldos al actualizar. Las pruebas automáticas de instalación y recuperación no sustituyen las comprobaciones físicas de cada equipo.
